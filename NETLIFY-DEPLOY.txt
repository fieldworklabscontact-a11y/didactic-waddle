NEST DEPLOY CHECKLIST
====================

1. Push the contents of this folder (the nest-direct repository root) to GitHub.
2. In Render, create a Blueprint from that repository and approve render.yaml, OR create a Docker Web Service with Root Directory `backend`.
3. Wait for Render to finish deploying. Open https://nest-python-bridge.onrender.com/health.
   Expected: {"status":"ok","scripts":{"embed":true,"extract":true}}
4. If Render gives your service a different URL, edit frontend/config.js and replace
   https://nest-python-bridge.onrender.com with that exact URL (no trailing slash).
5. In Netlify, import the same GitHub repository. Keep the included netlify.toml settings.
   The frontend base directory is `frontend`; publish directory is `.`.
6. Deploy the site. If you changed config.js after the first deploy, trigger a new deploy.
7. Open the Netlify site and test the embed/extract features.

IMPORTANT: Netlify hosts only the static frontend. The Python backend must be deployed
separately on Render (or another Python host). The Render free instance may sleep when
inactive, so its first request after inactivity can take longer.
